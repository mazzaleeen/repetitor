# Как добавлять материалы

## Самый простой способ — страница загрузки

Адрес: **https://mazzaleeen.github.io/repetitor/upload/** (на сайте ссылки на неё нет — сохраните в закладки).

1. Первый раз — создайте ключ доступа (инструкция «Где взять ключ» прямо на странице) и вставьте его.
2. Выберите класс и тему (или «+ Новая тема…»), тип — «Теория» или «Упражнения».
3. Выберите файл (можно несколько сразу) или вставьте ссылку, впишите название и описание.
4. Нажмите «Загрузить». Через 1–2 минуты материал на сайте.

Там же внизу — список материалов выбранной темы с кнопкой «Удалить».
Файлы — до 25 МБ; большие видео выкладывайте на Яндекс Диск или VK Видео и добавляйте ссылкой.

## Вручную через github.com

Всё ниже делается на сайте github.com в репозитории. После каждого сохранения («Commit changes»)
сайт обновляется сам примерно за 1–2 минуты.

## Где что лежит

```
материалы/
  6 класс/
  7 класс/
  …
  9 класс/
    1. Орфография/                        ← папка = тема на сайте
      1. Теория — Н и НН в разных частях речи.pdf
      2. Упражнения — Правописание приставок.pdf
      описания.txt                          ← короткие описания (по желанию)
      ссылки.txt                            ← ссылки вместо файлов (по желанию)
    2. Пунктуация/
настройки.toml                              ← имя, заголовок главной, классы
```

## Названия — это главное

**Папка темы:** `1. Орфография`
- номер в начале задаёт порядок тем на странице, на сайте его не видно;
- без номера темы идут по алфавиту.

**Файл:** `1. Теория — Н и НН в разных частях речи.pdf`
- `1.` — порядок внутри темы (необязательно);
- `Теория —` или `Упражнения —` — тип, по нему работает фильтр на сайте. Без типа считается «Теория»;
- дальше — название, как оно будет на сайте.

В именах файлов нельзя ставить двоеточие. Вместо него пишите ` - ` (дефис с пробелами) — на сайте он станет тире:
`Теория — Сжатое изложение - приёмы сжатия.pdf` → «Сжатое изложение — приёмы сжатия».

Можно загружать: PDF, Word, PowerPoint, Excel, картинки, аудио, видео. Размер одного файла — до 25 МБ.

## Добавить файл в существующую тему

1. Откройте `материалы` → нужный класс → нужную тему.
2. **Add file → Upload files**, перетащите файлы.
3. **Commit changes**.

## Создать новую тему

1. Откройте `материалы` → нужный класс.
2. **Add file → Upload files** и перетащите **папку** с файлами (например, `3. Изложение и сочинение`) — она загрузится целиком.

Или так: **Add file → Create new file**, в поле имени напишите `3. Изложение и сочинение/описания.txt`
(косая черта создаёт папку), сохраните — затем загрузите файлы в появившуюся папку.

## Описания под названиями (по желанию)

В папке темы создайте или откройте файл `описания.txt` (карандаш — редактировать) и пишите по строке на материал:

```
Н и НН в разных частях речи | Правила с примерами и списком исключений
Правописание приставок | Упражнения с ключами для самопроверки
```

Слева — название материала (как в имени файла), справа после `|` — описание.

## Ссылка вместо файла (видео, облачный диск)

В папке темы файл `ссылки.txt`, по строке на ссылку:

```
Упражнения — Тренировка сжатия | https://disk.yandex.ru/… | Тексты для самостоятельной работы
Теория — Видеоразбор НЕ с причастиями | https://vk.com/video…
```

Тип и название, ссылка, описание (необязательно) — через `|`.

## Убрать материал

Откройте файл → меню `…` справа вверху → **Delete file** → **Commit changes**.

Чтобы подготовить тему заранее и пока не показывать, назовите папку с подчёркиванием в начале: `_Черновик`.
Всё, что начинается с `_`, на сайт не попадает. Пример оформления лежит в `материалы/9 класс/_пример`.

## Изменить имя, заголовки и описания классов

Откройте `настройки.toml` → карандаш → меняйте **только текст в кавычках** → **Commit changes**.
Скрыть класс: у нужного класса поставьте `show = false`.

## Как понять, что всё получилось

Вкладка **Actions**: жёлтый кружок — сайт собирается, зелёная галочка — готово, красный крестик — ошибка
(чаще всего опечатка в `настройки.toml`: проверьте, что все кавычки на месте).

Материалы видят все посетители сайта. Не выкладывайте файлы с данными учеников и целиком отсканированные чужие пособия.
