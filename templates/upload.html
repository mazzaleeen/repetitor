Вход

Где взять ключ — один раз, около 5 минут
  1. Войдите на github.com в аккаунт {{ repo.split('/')[0] if repo else 'владельца репозитория' }} — ключ создаёт владелец репозитория.
  2. Откройте github.com/settings/personal-access-tokens/new (или: фото профиля → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token).
  3. Token name — например, «Сайт репетитора». Expiration — на год; когда срок выйдет, создайте новый ключ так же.
  4. Repository access → Only select repositories → выберите {{ repo.split('/')[1] if repo else 'репозиторий сайта' }}.
  5. Permissions → Repository permissions → Contents → Read and write. Остальное не трогайте.
  6. Нажмите Generate token, скопируйте ключ (начинается с github_pat_) и вставьте его выше. GitHub показывает ключ только один раз.

Ключ хранится только в этом браузере и никуда, кроме GitHub, не отправляется. Если телефон или компьютер потерян — удалите ключ на той же странице GitHub, и он перестанет работать.
