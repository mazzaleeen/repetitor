# Русский язык для 6–11 классов — сайт репетитора

Статический сайт на GitHub Pages: главная с карточками классов и страница каждого класса с материалами
по темам (поиск и фильтр «Теория / Упражнения»).

Материалы — это просто файлы в папке `материалы/<класс>/<тема>/`, имя и описания классов — в `настройки.toml`.
После каждого изменения GitHub сам собирает и публикует сайт (`.github/workflows/deploy.yml`).

- **Запустить сайт впервые** — `ЗАПУСК НА GITHUB.md`
- **Добавлять материалы** — `КАК ДОБАВЛЯТЬ МАТЕРИАЛЫ.md`

## Особенности

- Ничего не загружается со сторонних сервисов: шрифты Manrope и Unbounded (лицензия OFL) лежат в `static/fonts`.
- Нет форм, cookie и счётчиков — сайт не собирает данные посетителей.
- На сайт попадают только безопасные форматы файлов; всё, что начинается с `_`, пропускается.
- Файлы публикуются под латинскими именами, а скачиваются под исходным русским названием.

## Посмотреть на своём компьютере

Нужен Python 3.11+.

```
pip install -r requirements.txt
python build.py
python -m http.server -d _site
```

Откройте http://localhost:8000. Проверки: `python -m unittest discover tests`.

## Устройство

```
build.py               сборка: читает настройки и папку материалов, пишет готовый сайт в _site/
настройки.toml         имя, заголовки, список классов
материалы/             файлы материалов по классам и темам
templates/             HTML-шаблоны (Jinja2)
static/                стили, скрипт фильтра, шрифты
tests/                 проверки сборки и демонстрационные материалы
```
