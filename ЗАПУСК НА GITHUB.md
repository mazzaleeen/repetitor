# Запуск сайта на GitHub Pages — один раз, около 15 минут

Сайт бесплатно размещается на GitHub. Адрес будет вида `https://ИМЯ-АККАУНТА.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/`;
позже можно подключить свой домен (раздел в конце).

## 1. Аккаунт и репозиторий

1. Зарегистрируйтесь на github.com (лучше сразу на репетитора — так ей будет проще добавлять материалы).
2. Справа вверху «+» → **New repository**.
3. Название — латиницей, например `russkiy`. Оно попадёт в адрес сайта.
4. Выберите **Public** (бесплатный хостинг работает с публичными репозиториями).
5. Остальное не трогайте → **Create repository**.

## 2. Загрузка файлов

1. Распакуйте архив `russite-pages.zip` на компьютере.
2. На странице нового репозитория нажмите ссылку **uploading an existing file**.
3. Откройте распакованную папку `russite-pages`, выделите **всё её содержимое** (не саму папку) и перетащите в окно браузера.
4. Дождитесь загрузки и нажмите **Commit changes**.

**Проверьте папку `.github`.** На Mac она скрыта и может не загрузиться. Если в репозитории нет папки `.github`:
1. **Add file → Create new file**.
2. В поле имени напишите `.github/workflows/deploy.yml` (косые черты создадут папки).
3. Откройте этот файл из архива в Блокноте, скопируйте всё и вставьте.
4. **Commit changes**.

## 3. Включение сайта

1. В репозитории: **Settings → Pages**.
2. В блоке **Build and deployment** → **Source** выберите **GitHub Actions**.
3. Откройте вкладку **Actions** → слева «Публикация сайта» → **Run workflow** → **Run workflow**.
4. Через 1–2 минуты появится зелёная галочка. Адрес сайта будет в **Settings → Pages** вверху («Your site is live at …»).

Дальше сайт обновляется сам после каждого изменения: загрузили файл или поправили настройки — через пару минут всё на сайте.

## 4. Первые настройки

Откройте файл `настройки.toml` → значок карандаша → впишите имя, цены, Telegram и телефон → **Commit changes**.
Подробно — в файле «КАК ДОБАВЛЯТЬ МАТЕРИАЛЫ.md».

## Если что-то пошло не так

- **Красный крестик во вкладке Actions** — нажмите на него и откройте шаг с ошибкой.
  Частая причина — опечатка в `настройки.toml` (например, не закрыта кавычка). Исправьте файл, и сборка запустится снова.
- **Сайт не обновился** — подождите 2–3 минуты и обновите страницу с очисткой кэша (Ctrl+F5).

## Свой домен (по желанию)

1. Купите домен .ru у российского регистратора и пройдите идентификацию через Госуслуги.
2. **Settings → Pages → Custom domain** — впишите домен, сохраните, поставьте галочку **Enforce HTTPS**, когда она станет доступна.
3. В DNS домена добавьте записи, которые укажет GitHub (A-записи на адреса GitHub Pages или CNAME на `ИМЯ-АККАУНТА.github.io`).
4. Запустите «Публикация сайта» во вкладке Actions ещё раз — ссылки на сайте перестроятся под новый адрес.

## Ограничения GitHub Pages

- Весь сайт — до 1 ГБ, трафик — около 100 ГБ в месяц. Для материалов репетитора этого с запасом.
- Через браузер можно загрузить файл до 25 МБ. Большие видео лучше выкладывать на видеосервис и добавлять ссылкой.
- GitHub Pages не предназначен для интернет-магазинов и онлайн-бизнеса. Сайт-визитка с открытыми учебными материалами — обычное использование, но оплату через сайт сюда не добавляйте.
